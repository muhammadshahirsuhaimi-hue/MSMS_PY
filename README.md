# MSMS_PY

Python practice repository for LeetCode solutions.

## Structure

- Keep each problem in its own `.py` file.
- Use descriptive filenames, for example:
  - `two_sum.py`
  - `binary_tree_inorder_traversal.py`
- Add a short problem note or test snippet in the file if useful.

## Suggested layout

You can either keep files at the repo root or group them by topic, for example:

```text
arrays/
strings/
linked_list/
trees/
dynamic_programming/
```

## Run a file

```bash
python3 two_sum.py
```
